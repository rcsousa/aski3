# Semântica para Agentes de IA — Course Platform

Online course platform teaching semantics in the context of AI agents.

## Stack

- **Backend**: Python 3.12, FastAPI (async), SQLAlchemy 2 (async), Alembic, PostgreSQL
- **Frontend**: React 18, TypeScript, Vite, IBM Carbon Design System (`@carbon/react`)
- **State**: Zustand
- **Auth**: JWT (python-jose)
- **Knowledge layer**: rdflib, owlready2

## Running locally

```bash
docker compose up --build
# Frontend: http://localhost:3000
# Backend API: http://localhost:8000
# API docs: http://localhost:8000/docs
```

## Development (without Docker)

```bash
# Backend
cd backend
pip install -r requirements.txt
alembic upgrade head
uvicorn app.main:app --reload

# Frontend
cd frontend
npm install
npm run dev
```

## Project structure

```
backend/
  app/
    api/routes/     # FastAPI routers (auth, courses, sections, quiz, progress)
    core/           # config.py, security.py
    db/             # database.py (async SQLAlchemy engine)
    models/         # SQLAlchemy ORM models
    schemas/        # Pydantic v2 schemas
    services/       # content_loader.py (seeds DB from JSON fixtures)
  content/
    modules/
      module_01/content.json   # Module 1 content (generated by Content Agent)
      module_02/content.json   # Module 2 content
      module_03/content.json   # Module 3 content
  alembic/          # DB migrations

frontend/
  src/
    components/
      layout/       # AppShell, ProtectedRoute
      course/       # ProgressBar, lesson components
      quiz/         # Quiz components
      kg/           # Knowledge Graph visualizer (Phase 4)
    pages/          # LoginPage, CoursesPage, LessonPage, DashboardPage
    stores/         # authStore, courseStore (Zustand)
    types/          # TypeScript interfaces
    styles/         # Carbon SCSS overrides
```

## Content format

Each module's content lives in `backend/content/modules/module_XX/content.json`.
The `content_loader` service reads these on startup and upserts into the DB.
